# Translations

`de-en.json` maps German text strings from BMW EDIABAS SGBD files (fault location/type texts, environment-condition names, status texts, actuator names, job comments) to concise English. Keys are the source strings exactly as they appear in the SGBDs (latin-1 decoded), byte-for-byte.

- **Provenance:** translations were machine-generated by Claude from the SGBD texts and are **unreviewed** unless noted otherwise.
- **Usage:** r53diag looks up result text strings by exact match against the keys; strings with no entry are shown in the original German.
- **Omitted:** strings that are already English, proper names, or pure codes/numbers.
- **Updating:** `python tools/build_kb.py` regenerates `pending.json` with the strings that still lack a translation. Translate those and merge them into `de-en.json` (UTF-8, `ensure_ascii=False`, `indent=1`, keys sorted). `build_kb.py` never touches `de-en.json`.
